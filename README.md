# repotest

Repositorio de prueba para validar trazabilidad de Pull Requests en el sistema de gestión de proyectos.

## Propósito

Este repositorio se utiliza para probar la vinculación automática entre:
- Cards del tablero de proyecto
- Branches de Git
- Pull Requests de GitHub

## Trazabilidad

Cuando se crea un Pull Request desde el agente desarrollador, el sistema registra automáticamente el enlace SCM en la tarjeta correspondiente, permitiendo ver el estado del PR directamente en la pestaña DevOps de la card.
